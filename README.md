# Introdução
Este é um código programado em linguagem C++ tendo como objetivo simular uma partida de jogo da velha entre duas pessoas. Armazenando o resultado de vitoria de cada jogador em um arquivo denominado pontuacoes.txt, desta forma possibilitando a comparação entre os jogadores mesmo jogando partidas em dias diferentes. O código foi completamente comentado a fim de ajudar na compreensão da forma como ele funciona.
